# Glossary — PHire-Script-Sandbox

**`.phs` file**
PHireScript source file. Compiled to PHP by the PHireScript transpiler.

**`.phc` file**
Snapshot intermediate file generated by `php phirescript/bin/snapshot`. Represents a parsed/tokenized view of a `.phs` file.

**`.pht` file**
PHireScript test file. Used by the `validate` compiler command. Lives in `samples/feature/`.

**`pkg`**
Package declaration in PHireScript. Maps to a PHP namespace. Every `.phs` file must declare one.
Naming convention: `PHireScript.SamplesN` where N matches the case folder number.

**`use`**
Import statement in PHireScript. Supports grouped syntax: `use Pkg.{A, B as C}`.

**`external`**
Declares a PHP class from outside the PHireScript package system (e.g., `external Symfony\...\GlobFileLoader`).

**`type`**
PHireScript DTO declaration. Transpiles to a PHP value object. Can be `scoped`, `singleton`, or `newable`.

**`trait`**
PHireScript trait. Compiled to a PHP trait.

**`interface`**
PHireScript interface. Compiled to a PHP interface.

**`super type`**
A string-backed PHireScript primitive with built-in validation (e.g., `Email`, `Uuid`, `Ipv4`, `Color`, `Url`, `Cron`, `Duration`, `Date`, `Slug`).

**`scope modifier`**
Keyword after `as` in a class/type declaration: `newable`, `singleton`, or `scoped`.
- `newable` → instantiated with `new`
- `singleton` → single instance
- `scoped` → per-request instance

**`with`**
Applies a trait to a class: `class Foo with Logger`.

**`implements`**
Applies one or more interfaces: `class Foo implements A, B`.

**`CaseValidation.php`**
The orchestration controller for a test case. Extends `AbstractCaseValidation`. Declares tags/description via PHP attributes. Implements `execute()` to assert compiler output.

**`assertHasMessage(array)`**
Method on `AbstractCaseValidation`. Asserts that the compiler's captured stdout contains every string in the array. Normalizes ANSI codes and whitespace before comparison.

**`stopIfNoTest`**
Boolean property on `AbstractCaseValidation`. When `true`, the orchestrator fails the case if no `*Test.php` exists in the compiled output.

**`AbstractCaseValidation`**
Base class at `orchestrator/AbstractCaseValidation.php`. Provides: `execute()`, `before()`, `after()`, `executeTest()`, `assertHasMessage()`.

**`Orchestrator`**
Engine at `orchestrator/Orchestrator.php`. Scans `samples/{mode}/`, loads cases, filters by tags, drives mode lifecycle.

**`SuccessMode`**
Mode handler at `samples/success/SuccessMode.php`. Wraps `Compiler::compile()` in output buffering, sets test config.

**`ConfigModifier`**
Backs up and restores `PHireScript.json` around each test case to ensure isolation.

**`FileManager`**
Copies case source files into `src/output/` before compilation; clears afterwards.

**`PHireScript.json`**
JSON config read by the compiler. Fields: `dev`, `namespace`, `currency`, `resolver`, `paths.source`, `paths.dist`, `paths.test`.

**`#[Tag('...')]`**
PHP 8 repeatable attribute. Applied to `CaseValidation` classes for filtering via `--tags=`.

**`#[Description('...')]`**
PHP 8 attribute. Human-readable description of the case.

**`#[Documentation(true|false)]`**
PHP 8 attribute. Marks whether the case is documented for external reference.
